## 1. Project Overview

**HandsMen Threads** is a Salesforce-based business management solution designed for a fashion retail organization. It centralizes customer, product, order, inventory, and marketing information within a single platform while using Salesforce automation to streamline business operations.

The project integrates custom objects and fields with lookup and master-detail relationships, formula fields, validation rules, profiles, roles, permission sets, email templates, record-triggered flows, scheduled automation, Apex triggers, Batch Apex, and Scheduled Apex.

### Key Business Outcomes

* Automatically send order confirmation notifications when an order is confirmed.
* Determine and update customer loyalty status based on purchase history.
* Alert the inventory team when product stock reaches a defined low-stock level.
* Calculate order amounts and manage inventory deductions for confirmed orders.
* Automate inventory restocking through scheduled Batch Apex processing.
